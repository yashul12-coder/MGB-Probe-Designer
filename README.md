# MGB Probe Designer v3.0

Open-source GUI for designing multiplex MGB Eclipse probes for SNP genotyping.
Features: Short probes (13-18nt), BLAST-like off-target check, 3'-clamp, qPCR-optimized Tm (66-70°C).

## Installation
pip install -r requirements.txt

## Usage
python mgb_probe_designer_v3.py

Drag FASTA with _REF/_ALT pairs → Run Design → Export Excel.
